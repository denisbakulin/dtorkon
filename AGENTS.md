# Project Agent Notes

## Project Summary

Проект развивается как мини-блог с публичной витриной и приватной авторской админкой. Это docs-first продукт с frontend, FastAPI backend, SQLite и Yandex Object Storage.

## Current Scope

- держать документацию синхронной с логикой;
- развивать публичный блог и приватную админку как основную систему;
- использовать React, MUI и Axios во frontend-слое;
- использовать FastAPI и async SQLAlchemy в backend;
- хранить посты и сессии в SQLite;
- хранить изображения и файлы в Yandex Object Storage;
- сохранять VPS-first деплой через Docker Compose и Caddy;
- поддерживать два режима: локальный `localhost` и глобальный доменный запуск.

## Documentation Contract

- `openapi.json` — каноничный контракт API;
- документы из `docs/` — рабочие артефакты, а не заметки;
- любое изменение логики обновляет связанные документы в том же изменении;
- любое изменение API обновляет `openapi.json` и `docs/API_GUIDE.md`;
- любое изменение данных обновляет `docs/DATABASE.md`;
- если код и документация расходятся, работа не завершена.

## Working Rules

- держать решения простыми, но пригодными для реального мини-блога;
- предпочитать понятную модульную структуру без лишней сложности;
- не оставлять архитектурные развилки незафиксированными в документации;
- инфраструктурные файлы группировать отдельно от исходников;
- использовать встроенную автоматизацию TLS там, где она надежнее ручных скриптов;
- визуальный вектор frontend считать зафиксированным: минималистичный MUI-дизайн в стиле Telegram;
- legacy-артефакты старого лендинга не считать источником правды.

## Preferred Skills

- использовать `browser-use:browser` для локальной проверки интерфейса после frontend-изменений;
- использовать GitHub skills только если работа реально связана с PR, issue или CI;
- обращаться к внешней документации только при необходимости точных ссылок;
- при работе с UI учитывать MUI и согласованность дизайн-системы.

## Expected Deliverables

- согласованная документационная система;
- каноничный API-контракт в `openapi.json`;
- ясная архитектура frontend, backend, базы и деплоя;
- понятный путь от текущего состояния к полноценному мини-блогу;
- правила, по которым дальше можно безопасно реализовывать продукт.
