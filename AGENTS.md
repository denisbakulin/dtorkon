# Project Agent Notes

## Project Summary

Проект нужен для быстрой проверки, что новый домен, настроенный через Cloudflare, корректно отдает тестовый лендинг по HTTPS.

## Current Scope

- собрать небольшой React-лендинг;
- использовать MUI и Axios;
- отдать фронтенд как статическую сборку через Caddy;
- подготовить Docker Compose;
- предусмотреть автоматический HTTPS для домена.

## Working Rules

- держать решения простыми и расширяемыми;
- не добавлять лишний backend, если задача решается статикой;
- предпочитать понятную feature-структуру с минимальным числом сущностей;
- инфраструктурные файлы группировать отдельно от исходников фронтенда;
- предпочитать встроенную автоматизацию TLS вместо внешних скриптов, если она надежнее;
- любые новые папки и файлы называть так, чтобы их назначение было очевидно.

## Preferred Skills

- использовать `browser-use:browser` для локальной проверки интерфейса после фронтенд-изменений;
- использовать GitHub skills только если работа реально связана с PR, issue или CI;
- обращаться к внешней документации только при необходимости точных и актуальных ссылок.
- скилл работы с mui

## Expected Deliverables

- рабочая структура проекта;
- минимальный, но аккуратный лендинг;
- dockerized-сборка с Caddy;
- инструкции по запуску и обслуживанию.
