# CODE_STYLE

## Общие принципы

- код должен быть понятным без долгого онбординга;
- простота важнее избыточной абстракции;
- комментарии добавляются только там, где логика реально неочевидна.

## Frontend

- React + TypeScript;
- route-level код живет в `pages/`;
- крупные композиции — в `widgets/`;
- прикладная логика — в `features/`;
- общие примитивы, API-клиент и утилиты — в `shared/`;
- MUI используется как основа дизайн-системы;
- интерфейс остается минималистичным и функциональным.

## Backend

- backend делится на `http`, `application`, `domain`, `infrastructure`;
- HTTP-роуты не должны напрямую содержать SQL и S3-логику;
- все значения из env проходят через единый config layer;
- repository contract должен быть явным.

## Docs sync

- изменение логики без обновления документов запрещено;
- изменение API без обновления `openapi.json` запрещено;
- изменение схемы данных без обновления `docs/DATABASE.md` запрещено;
- изменение инфраструктуры без обновления `docs/DEVOPS_DEPLOY.md` запрещено.
